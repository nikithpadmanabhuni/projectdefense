🔒 Privacy & Data Transparency:

What is stored: All student profile info, checklist checkboxes, resume drafts, sprint tasks, and coding attempts are stored strictly in localStorage on your device only.

What is transmitted: When you load a repository in Project Defense, code is fetched directly from the public GitHub REST API. If Live AI mode is configured, only the selected code file is processed for questions. Nothing is stored on our servers.

No account required: We do not collect passwords, email addresses, or track your identity across sessions.
